# LayoutFixer

Переключатель раскладки для macOS: превращает `ghbdtn` в `привет`, а `руддщ` в `hello`. Маленький, открытый и намеренно ничего не запоминает из набранного.

Работает в строке меню, значок — клавиша **A/Ф**.

## Возможности

- **Автопереключение раскладки.** После пробела или знака препинания слово проверяется по встроенным словарям macOS. Если в текущей раскладке это не слово, а в другой — слово, оно заменяется, и раскладка переключается: `yblthkfyls` → `Нидерланды`.
- **Исправление опечаток.** `менб` → `меню`, `првиет` → `привет`, `recieve` → `receive`. Из вариантов выбирается ближайший по клавиатуре, поэтому `менб` становится `меню`, а не `меня`.
- **Принудительный перевод слова** по горячей клавише — работает и тогда, когда слова нет в словаре.
- **Действия с выделенным текстом:** сменить раскладку, сменить регистр (`пРИВЕТ` → `Привет`), транслитерация (`привет` ↔ `privet`).
- **Отмена замены** одной клавишей. Отменённое слово попадает в исключения и больше не трогается.
- **Автозамена сокращений:** `спс` → `Спасибо!`. Срабатывает в любой раскладке.
- **Исключения** по словам и по программам.
- **Выбор словарей.** По умолчанию русский и английский (США). В разделе «Языки» можно включить английский (Великобритания), испанский, немецкий и другие словари, установленные в macOS.

## Языки

Замена работает между латиницей и кириллицей: программа сама определяет алфавит включённых раскладок, поэтому подойдёт любая пара, например испанская и русская.

Слово считается правильным, если оно есть хотя бы в одном включённом словаре своего алфавита. Чем больше словарей включено, тем реже срабатывает замена: слова из разных языков начинают считаться правильными. И наоборот — с выключенным словарём слова этого языка могут исправляться как опечатки: `gracias` без испанского словаря может быть принято за опечатку.

Китайского нет: в macOS нет такого словаря, а сам китайский набирается методом ввода (пиньинь), а не раскладкой, поэтому подменять буквы там нечего. Когда активен метод ввода, программа не вмешивается.

## Приватность

Программа написана для личного пользования, и главное требование к ней было — не собирать набранный текст.

- Нажатия клавиш не пишутся на диск. В памяти живёт только текущее слово и последнее слово (для отмены), и очищается после каждого пробела, клика мышью и смены программы.
- Журнала набранного текста нет и не будет.
- Сети нет совсем: в коде ни одного сетевого вызова.
- Поля паролей пропускаются: там macOS включает защищённый ввод, плюс программа сама проверяет тип поля и игнорирует менеджеры паролей.
- Слова с цифрами, `@`, точками и подчёркиваниями не трогаются, поэтому логины остаются как есть.
- На диск сохраняются только настройки и списки, которые вы видите в окне: слова-исключения (`~/Library/Application Support/LayoutFixer/exceptions.txt`) и ваши сокращения (`~/Library/Preferences/local.layoutfixer.plist`).

## Установка

Скачайте `LayoutFixer.dmg` из раздела Releases, откройте и перетащите программу в «Программы».

При первом запуске macOS попросит доступ: «Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ» → добавить LayoutFixer через «+» и включить переключатель. Без этого доступа программа не видит клавиатуру.

Нужны включённые английская и русская раскладки.

## Сборка из исходников

```bash
./build.sh      # собирает build/LayoutFixer.app
./make_dmg.sh   # собирает build/LayoutFixer.dmg
```

Нужен только Xcode Command Line Tools — сторонних библиотек нет. Иконка рисуется при сборке (`make_icon.swift`), картинок в репозитории нет.

Программа подписывается временной подписью. Она меняется при каждой сборке, поэтому после обновления разрешение на клавиатуру приходится выдавать заново. Чтобы этого избежать, подпишите своим постоянным сертификатом:

```bash
codesign --force --sign "Имя вашего сертификата" build/LayoutFixer.app
```

## Горячие клавиши

| Действие | По умолчанию |
|---|---|
| Отменить замену | ⌥+Пробел |
| Сменить раскладку слова (принудительно) | правый ⌥ |
| Сменить раскладку выделенного | правый ⌘ |
| Сменить регистр выделенного | не задано |
| Транслитерация выделенного | не задано |

Всё меняется в окне настроек, там же можно записать своё сочетание. ⌘+Пробел и ⌃+Пробел macOS обычно занимает сама (Spotlight и смена раскладки) — до программы они не доходят, пока вы не освободите их в настройках клавиатуры.

## Как это устроено

- Нажатия перехватываются через `CGEventTap` в отдельном потоке. В этом потоке нет ни одного вызова, который ждёт ответа системы: любое ожидание там останавливает ввод во всей системе.
- Обработчик только запоминает коды клавиш. Решение принимается следом, в главном потоке, и замена делается уже после того, как символ напечатался.
- Раскладки читаются через `UCKeyTranslate` из системных таблиц, поэтому программа не зависит от варианта раскладки («Русская» или «Русская — ПК»).
- Слова проверяются через `NSSpellChecker` — встроенные словари macOS, локально.

## Ограничения

- Только английская и русская раскладки.
- Замена зависит от словарей macOS: сленг, имена и редкие названия остаются как есть — для них принудительный перевод по клавише.
- Слова короче двух букв автоматически не заменяются.
- В отдельных программах (обычно на Electron) вставка текста может срабатывать не всегда.
